행복공고 — 개인정보처리방침

시행일: 2026-10-06
운영: Blankroute / 행복공고 (com.blankroute.haengbok)

행복공고는 행복주택 모집 공고를 모아 보여 주는 앱입니다. 공식 청약 앱이 아니며, 신청은 LH 청약플러스에서 합니다. 공고 내용의 최종 확인은 공고문이고, 이 앱은 자격 충족 여부를 판정하지 않습니다.

1. 수집·저장하는 정보

항목저장 위치목적
시작 동의 여부기기고지를 다시 보이지 않기 위함
즐겨찾기, 공고 알림 설정기기앱 기능 제공
위치(대략 또는 정확한 위치)권한을 허용한 때 기기 지도, Google 지도지도에 현재 위치 표시
공고 주소의 좌표기기에 저장. 찾지 못하면 공개 주소 문자열만 지오코딩 서비스로 전송공고 위치를 지도에 표시

계정 로그인은 없습니다. 광고 SDK와 광고 ID를 사용하지 않습니다. 즐겨찾기와 알림 설정은 기기에만 저장되며 서버로 보내지 않습니다.

2. 제3자

  • Google Maps Platform: 지도 표시와, 권한을 허용한 경우 현재 위치 표시
  • 공고 서버: 저장된 공공 공고 데이터를 불러오기 위해 접속합니다. 이용자 계정은 보내지 않습니다.
  • OpenStreetMap Nominatim: 기기 지오코딩이 공고 주소를 못 찾으면, 해당 공고의 공개 주소 문자열만 보냅니다.

3. 보관·파기

기기에 저장된 동의, 즐겨찾기, 알림 설정, 좌표는 앱 데이터를 삭제하면 기기에서 지워집니다. 서버에 이용자 계정 정보는 보관하지 않습니다.

4. 이용자 권리

위치 권한은 기기 설정에서 거부할 수 있습니다. 문의: azellpop@gmail.com
